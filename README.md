# Campus Assistant Bot

## Project Description
This is a Python-based chatbot that helps students get information about timetable, exams, faculty, and events.

## Features
- Timetable information
- Exam details
- Faculty information
- Event updates

## Files in this project
- campus_assistant.py (main Python code)
- flowchart.png (project flowchart)

## How to Run
Run the following command in terminal:
python campus_assistant.py
